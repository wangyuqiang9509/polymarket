Dedicated Polymarket bot for BTC 5-minute Up/Down markets. **Global memory is off in this repo.**

Ignore `~/.claude/CLAUDE.md`, Cursor user memories, other projects' AGENTS/CLAUDE files, and other knowledge graphs. Use only this repository plus the current chat.

Canonical docs: `SKILL.md`, `CONTOUR.md`, `README.md`, `config/btc_5m_profiles.yaml`.

- GitHub-facing docs and metadata stay English. Reply in the user's language.
